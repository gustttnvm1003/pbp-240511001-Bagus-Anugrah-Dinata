# 📱 Pertemuan 3: Responsive Design (LKP 2B)

Folder ini berisi kelanjutan dari proyek halaman profil pribadi, yang merupakan pengerjaan **Lembar Kerja Praktikum (LKP) 2B**.

## 🎯 Tujuan Praktikum
1. Menerapkan prinsip *Responsive Web Design* menggunakan pendekatan *Mobile-First*.
2. Memanfaatkan **Media Queries** CSS (`@media`) agar tata letak web dapat beradaptasi secara otomatis pada berbagai ukuran layar.
3. Melakukan pengujian responsivitas pada ukuran layar Mobile, Tablet, dan Desktop.

## 📂 Struktur File
*   `index.html` - Kerangka utama halaman web profil (Sama dengan LKP 2A).
*   `style.css` - Berkas styling yang sudah diperbarui dengan tambahan sintaks Media Queries.
*   `screenshot-375.png` - Bukti pengujian tata letak pada layar Mobile (375px).
*   `screenshot-768.png` - Bukti pengujian tata letak pada layar Tablet (768px).
*   `screenshot-1200.png` - Bukti pengujian tata letak pada layar Desktop (1200px).

## 🚀 Cara Pengujian
Buka file `index.html` di web browser, tekan tombol `F12` untuk membuka *Developer Tools*, lalu gunakan fitur *Device Toggle* untuk mengubah ukuran resolusi layar dan melihat transisi perubahannya.
