# 🌐 Pertemuan 2: HTML5 & CSS Dasar (LKP 2A)

Folder ini berisi hasil pengerjaan **Lembar Kerja Praktikum (LKP) 2A**. Pada tahap ini, saya membangun halaman profil pribadi statis.

## 🎯 Tujuan Praktikum
1. Membangun struktur halaman web menggunakan HTML5 Semantik (`<header>`, `<nav>`, `<main>`, `<section>`, dll).
2. Menerapkan eksternal CSS untuk styling dasar (warna, font, margin, padding).
3. Mengimplementasikan layout modern menggunakan **Flexbox** dan **CSS Grid**.

## 📂 Struktur File
*   `index.html` - Kerangka utama halaman web profil.
*   `style.css` - Berkas styling untuk mengatur tata letak dan estetika halaman web.
*   `assets/foto.jpg` - Direktori penyimpanan aset gambar profil.

## 🚀 Cara Melihat Hasil
Silakan unduh atau *clone* folder ini, lalu buka file `index.html` menggunakan web browser pilihan Anda untuk melihat hasil render halaman web statis.
